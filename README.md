# Persian Marketplace UI/UX Research

Research notes on UI/UX patterns for Persian (Farsi, RTL) marketplaces.

## Scope
- RTL layout, typography (Vazirmatn and system fonts), numbers/dates (Jalali, Persian digits)
- Marketplace flows: home, search, PLP/PDP, cart, checkout, payments (Shaparak/PSP), shipping, returns
- Trust signals: reviews, seller badges, guarantees, support
- Comparisons: Digikala, Torob, Emalls, Bamilo-era patterns vs. global (Amazon, Trendyol, etc.)

## Repo Structure
- `research/` — notes, findings (Markdown)
- `assets/` — screenshots, diagrams
- `references.md` — sources and links

## Conventions
- Markdown, one topic per file
- Screenshots in `assets/` with descriptive names
- RTL screenshots annotated where relevant
